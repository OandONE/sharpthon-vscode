# SharpThon for VS Code

Syntax highlighting and language support for SharpThon (`.spy`) files.

## Features

- Syntax highlighting for `.spy` files
- Code snippets (`def`, `class`, `if`, `for`, `while`, `import`, `go`, `await`, etc.)
- Block and line comments (`//`, `/* */`)
- Auto-closing brackets and quotes

## Install

Copy this folder to `~/.vscode/extensions/`:

```bash
cp -r sharpthon-vscode ~/.vscode/extensions/
```

Restart VS Code.
